# Canada Study Choice

面向中国高中生探索加拿大专上教育项目与升学路径的技能。它以可负担性为先，只收集做出判断所必需的信息；对会变化的项目、费用、要求和截止日期，只使用官方来源；输出可追溯理由的个人探索报告，而不是不透明的排名。

## 能做什么

- 在列出具体学校、项目或路径前，先完成预算与家长确认关卡。
- 分开比较第一学年与完整项目周期的费用，并标明计算范围、假设、估算和未知项。
- 核验项目名称、适用学生类别、入学学期、费用、入学要求与截止日期是否来自官方来源。
- 为每个候选项展示：学生事实、已核验项目事实、含义，以及仍需确认的事项。
- 当财务、适配性或官方证据不完整时，停止给出个体候选推荐，转为说明下一步需要补充什么。

## 不能做什么

本技能不保证录取、奖学金、就业、薪资、资金或学签结果；不提供法律、移民、税务、投资或财务建议；也不替学生或家庭作最终决定。

学校信息会变化。在申请、付款、缴纳押金或提交材料前，应由学生和家庭直接向相关院校独立确认项目、费用、要求与截止日期。

## 隐私与敏感资料

仅提供评估选项所必需的信息。不要提供账号或密码、政府身份证件、银行账户信息、完整财务报表、资金证明文件，或与决策无关的家庭资料。精确金额并非必要时，应使用区间。

本技能只能约束对话应索取的信息，不能决定宿主平台、模型提供商、集成服务或未来修改版本如何存储或处理数据。分享个人信息前，请自行阅读所使用平台的隐私条款。

## 使用方式

在兼容的宿主中调用：

```text
Use $canada-study-choice to explore affordable Canadian post-secondary options for one Grade 12 student, starting with the minimum information needed.
```

主说明位于 `SKILL.md`。收集或评估个人信息前，请阅读 `references/intake-and-gates.md`；研究具体候选项或撰写候选报告前，请阅读 `references/research-and-report.md`。

## 可选人工复核

当技能停止推荐，或家庭希望获得更深入的协助时，可选择将安全交接摘要提供给 Kevin Shu Studio。该转介不代表任何候选项已获认可，也不承诺结果。更多信息可访问 [kevinshustudio.com](https://kevinshustudio.com)。除非已提供经核实的公开账号名称或链接，技能不得声称存在某个小红书账号。

## 来源与内容权利

技能应概述信息并链接至权威来源。未经许可，不应把院校的大段文字、表格、标志或其他第三方内容复制到再发布版本中。
